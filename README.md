# IP 子網計算器

以繁體中文提供的瀏覽器版 IP 子網計算器，支援 IPv4、IPv6、CIDR 與 VLSM。介面和計算邏輯都包含在單一 `index.html` 檔案中，不需要安裝套件或建置。

## 功能

- **IPv4 子網計算**：輸入 IP 與前綴長度或子網遮罩，查看網路位址、廣播位址、位址範圍、可用主機數及位元分布。
- **IPv6 子網計算**：輸入 IPv6 位址與前綴，查看網路資訊及常用表示法。
- **子網分割與 VLSM**：依子網數量、每個子網的主機數或新前綴分割 IPv4 網路；依主機需求規劃 VLSM。
- **轉換工具**：轉換 IPv4 表示法、子網遮罩／CIDR／萬用遮罩，將 IP 範圍轉為 CIDR，檢查 IP 是否屬於子網，計算最小共同網路，並壓縮或展開 IPv6 位址。
- **對照表**：瀏覽 IPv4 CIDR 資訊及常用 IPv6 前綴。
- **介面便利功能**：支援複製結果、淺色／深色外觀及小螢幕版面。

## 使用方式

直接以現代瀏覽器開啟 `index.html` 即可使用。也可以將此專案部署至任何可提供靜態檔案的網頁伺服器，並開啟其 `index.html`。

## 技術需求

IPv6 計算使用 JavaScript `BigInt`，請使用支援 `BigInt` 的現代瀏覽器。頁面載入 IBM Plex 字型時會連線至 Google Fonts；若無法連線，將使用系統字型。
